# Griductive-Solver

Dự án giải đố và mô phỏng trò chơi logic **Griductive** (Grid Deduction Logic Puzzle) sử dụng thuật toán **DPLL (SAT Solver)** và giao diện đồ họa **Pygame**.

Môn học: Cơ sở Trí tuệ Nhân tạo (CSAI) - Trường Đại học Khoa học Tự nhiên, ĐHQG-HCM.

---

## Bắt đầu nhanh

### 1. Cài đặt thư viện

```bash
python -m venv .venv
# Kích hoạt venv (Windows): .venv\Scripts\Activate.ps1
# Kích hoạt venv (Linux/macOS): source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Chạy chương trình

```bash
cd Source
python main.py
```
